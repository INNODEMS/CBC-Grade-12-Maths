    Subsection 14.2.1 Indefinite Integrals of Polynomials

    Learner Experience 14.2.1 Term by Term.

    1. Differentiate \(x^3 + 2x^2 - 5x + 7\text{.}\)
      🔗
      🔗
    2. Hence write down \(\displaystyle\int (3x^2 + 4x - 5)\,dx\text{.}\)
      🔗
      🔗
    3. Now integrate each term of \(3x^2 + 4x - 5\) separately and add the results. Do you get the same answer?
      🔗
      🔗
    4. Is \(\displaystyle\int 4x^2\,dx\) equal to \(4\displaystyle\int x^2\,dx\text{?}\)
      🔗
      🔗
    5. Wanjiru says \(\displaystyle\int (x + 1)(x + 2)\,dx = \left(\frac{x^2}{2} + x\right)\left(\frac{x^2}{2} + 2x\right) + c\text{.}\) Expand her answer and differentiate it. Is she right?
      🔗
      🔗
    🔗
    🔗

    Key Takeaway 14.2.2 Integrating Polynomials.

    \begin{equation*} \int \bigl(f(x) + g(x)\bigr)\,dx = \int f(x)\,dx + \int g(x)\,dx, \qquad \int k f(x)\,dx = k\int f(x)\,dx \end{equation*}
    So a polynomial is integrated term by term, with one constant of integration for the whole answer. Multiply out any brackets before you integrate.
    🔗
    🔗

    Warning 14.2.3 Expand First.

    The integral of a product is not the product of the integrals. Wanjiru’s answer in Learner Experience 14.2.1 differentiates to a cubic, not to \((x + 1)(x + 2)\text{.}\) Multiply out first, then integrate term by term.
    🔗
    🔗

    Example 14.2.4 A Cubic Term by Term.

    Find \(\displaystyle\int (4x^3 - 6x^2 + 2x - 7)\,dx\text{.}\)
    🔗
    Solution.
    Integrate each term:
    \begin{equation*} \int (4x^3 - 6x^2 + 2x - 7)\,dx = \frac{4x^4}{4} - \frac{6x^3}{3} + \frac{2x^2}{2} - 7x + c = x^4 - 2x^3 + x^2 - 7x + c \end{equation*}
    Check: the derivative is \(4x^3 - 6x^2 + 2x - 7\text{.}\)
    🔗
    🔗
    🔗

    Example 14.2.5 Expanding a Product.

    Find \(\displaystyle\int (x - 2)(3x + 1)\,dx\text{.}\)
    🔗
    Solution.
    Expand first: \((x - 2)(3x + 1) = 3x^2 + x - 6x - 2 = 3x^2 - 5x - 2\text{.}\) Then
    \begin{equation*} \int (3x^2 - 5x - 2)\,dx = x^3 - \frac{5x^2}{2} - 2x + c \end{equation*}
    🔗
    🔗
    🔗

    Example 14.2.6 A Squared Bracket.

    Find \(\displaystyle\int (2x + 3)^2\,dx\text{.}\)
    🔗
    Solution.
    \((2x + 3)^2 = 4x^2 + 12x + 9\text{,}\) so
    \begin{equation*} \int (2x + 3)^2\,dx = \frac{4x^3}{3} + 6x^2 + 9x + c \end{equation*}
    🔗
    A tempting answer is \(\frac{(2x + 3)^3}{3}\text{.}\) Its derivative is \(2(2x + 3)^2\text{,}\) twice the integrand, so it is wrong.
    🔗
    🔗
    🔗
    Type powers with ^ and the constant of integration as c, for example x^3/3+2x+c.

    Subsection 14.2.2 Definite Integrals

      🔗
      🔗
    🔗
    🔗

    Key Takeaway 14.2.10 Definite Integrals.

    If \(F(x)\) is any integral of \(f(x)\text{,}\) the definite integral of \(f(x)\) from \(a\) to \(b\) is
    \begin{equation*} \int_{a}^{b} f(x)\,dx = \left[ F(x) \right]_{a}^{b} = F(b) - F(a)\text{.} \end{equation*}
    Here \(a\) is the lower limit and \(b\) the upper limit. The answer is a number: the constant of integration cancels, so leave it out. Swapping the limits changes the sign: \(\int_{b}^{a} f(x)\,dx = -\int_{a}^{b} f(x)\,dx\text{.}\)
    🔗
    🔗

    Example 14.2.11 Evaluating a Definite Integral.

    Evaluate \(\displaystyle\int_{1}^{3} (3x^2 - 2x)\,dx\text{.}\)
    🔗
    Solution.
    \begin{equation*} \int_{1}^{3} (3x^2 - 2x)\,dx = \left[ x^3 - x^2 \right]_{1}^{3} = (27 - 9) - (1 - 1) = 18 - 0 = 18 \end{equation*}
    🔗
    🔗
    🔗

    Example 14.2.12 A Negative Lower Limit.

    Evaluate \(\displaystyle\int_{-1}^{2} (x^3 + 2x)\,dx\text{.}\)
    🔗
    Solution.
    \begin{equation*} \int_{-1}^{2} (x^3 + 2x)\,dx = \left[ \frac{x^4}{4} + x^2 \right]_{-1}^{2} = \left(\frac{16}{4} + 4\right) - \left(\frac{(-1)^4}{4} + (-1)^2\right) = 8 - \frac{5}{4} = \frac{27}{4} = 6.75 \end{equation*}
    Put the negative limit in brackets: \((-1)^4 = 1\) and \((-1)^2 = 1\text{.}\)
    🔗
    🔗
    🔗

    Example 14.2.13 Expanding Before Evaluating.

    Evaluate \(\displaystyle\int_{0}^{2} (x + 1)(x - 3)\,dx\text{.}\)
    🔗
    Solution.
    \((x + 1)(x - 3) = x^2 - 2x - 3\text{,}\) so
    \begin{equation*} \int_{0}^{2} (x^2 - 2x - 3)\,dx = \left[ \frac{x^3}{3} - x^2 - 3x \right]_{0}^{2} = \left(\frac{8}{3} - 4 - 6\right) - 0 = -\frac{22}{3} \approx -7.33 \end{equation*}
    A definite integral can be negative. Section Section 14.3 explains what that means.
    🔗
    🔗
    🔗

    Example 14.2.14 Finding a Limit.

    Given that \(\displaystyle\int_{1}^{k} (2x + 1)\,dx = 10\text{,}\) where \(k \gt 1\text{,}\) find \(k\text{.}\)
    🔗
    Solution.
    \(\left[ x^2 + x \right]_{1}^{k} = (k^2 + k) - 2\text{.}\) So \(k^2 + k - 2 = 10\text{,}\) that is \(k^2 + k - 12 = 0\text{,}\) and \((k + 4)(k - 3) = 0\text{.}\)
    🔗
    Since \(k \gt 1\text{,}\) \(k = 3\text{.}\) (The root \(k = -4\) is rejected.)
    🔗
    🔗
    🔗
    Type exact values as whole numbers, fractions or decimals, for example 27/4 or 6.75. Type an expression in k with ^ for powers, for example k^2+3k-4.

    3.

    Evaluate \(\displaystyle\int_{-2}^{1} (x^2 + 2)\,dx\text{.}\)
    🔗
    Answer.
    \(9\)
    🔗
    🔗
    Solution.
    \(\left[ \frac{x^3}{3} + 2x \right]_{-2}^{1} = \left(\frac{1}{3} + 2\right) - \left(-\frac{8}{3} - 4\right) = \frac{7}{3} + \frac{20}{3} = 9\text{.}\)

    4.

    Evaluate \(\displaystyle\int_{1}^{3} (x^3 - 2x)\,dx\text{.}\)
    🔗
    Answer.
    \(12\)
    🔗
    🔗
    Solution.
    \(\left[ \frac{x^4}{4} - x^2 \right]_{1}^{3} = \left(\frac{81}{4} - 9\right) - \left(\frac{1}{4} - 1\right) = \frac{45}{4} + \frac{3}{4} = 12\text{.}\)

    5.

    Evaluate \(\displaystyle\int_{0}^{3} (x - 1)(x + 2)\,dx\text{.}\)
    🔗
    Answer.
    \(\frac{15}{2} = 7.5\)
    🔗
    🔗
    Solution.
    \((x - 1)(x + 2) = x^2 + x - 2\text{;}\) \(\left[ \frac{x^3}{3} + \frac{x^2}{2} - 2x \right]_{0}^{3} = 9 + \frac{9}{2} - 6 = \frac{15}{2}\text{.}\)
    🔗

    6.

    Given that \(\displaystyle\int_{0}^{k} (3x^2 + 2)\,dx = 12\text{,}\) find \(k\text{.}\)
    🔗
    Answer.
    \(k = 2\)
    🔗
    🔗
    Solution.
    \(k^3 + 2k = 12\text{.}\) Trying \(k = 2\text{:}\) \(8 + 4 = 12\text{.}\) Since \(k^3 + 2k\) increases as \(k\) increases, this is the only solution.

    7.

    A tank is filled through a valve. After \(t\) minutes water flows in at \(\dfrac{dV}{dt} = 40 - 2t\) litres per minute, for \(0 \le t \le 10\text{.}\) How much water flows in during the first \(10\) minutes?
    🔗
    Answer.
    \(300\,\text{litres}\)
    🔗
    🔗
    Solution.
    \(\displaystyle\int_{0}^{10} (40 - 2t)\,dt = \left[ 40t - t^2 \right]_{0}^{10} = 400 - 100 = 300\,\text{litres}\text{.}\)

    8.

    Show that \(\displaystyle\int_{-a}^{a} x^3\,dx = 0\) for every number \(a\text{.}\)
    🔗
    Answer.
    \(\frac{a^4}{4} - \frac{(-a)^4}{4} = 0\)
    🔗
    🔗
    Solution.
    \(\left[ \frac{x^4}{4} \right]_{-a}^{a} = \frac{a^4}{4} - \frac{(-a)^4}{4} = \frac{a^4}{4} - \frac{a^4}{4} = 0\text{,}\) because \((-a)^4 = a^4\text{.}\)

    9. Challenge: An Unknown Coefficient.

    Given that \(\displaystyle\int_{1}^{3} (ax + 2)\,dx = 20\text{,}\) find the constant \(a\text{.}\)
    🔗
    Hint.
    The integral works out to \(4a + 4\text{.}\)
    🔗
    🔗
    Answer.
    \(a = 4\)
    🔗
    🔗
    Solution.
    \(\left[ \frac{ax^2}{2} + 2x \right]_{1}^{3} = \left(\frac{9a}{2} + 6\right) - \left(\frac{a}{2} + 2\right) = 4a + 4\text{.}\) So \(4a + 4 = 20\) and \(a = 4\text{.}\)

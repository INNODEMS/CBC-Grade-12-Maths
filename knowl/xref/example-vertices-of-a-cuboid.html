Example 10.1.7 Vertices of a Cuboid.

A cuboid \(OABCDEFG\) has \(O\) at the origin, \(OA = 5\) along the \(x\)-axis, \(OC = 3\) along the \(y\)-axis and \(OD = 2\) up the \(z\)-axis. Its base is \(OABC\text{,}\) and \(D\text{,}\) \(E\text{,}\) \(F\text{,}\) \(G\) are above \(O\text{,}\) \(A\text{,}\) \(B\text{,}\) \(C\text{.}\) This cuboid is labelled from the origin \(O\text{,}\) unlike the \(ABCDEFGH\) labelling used in Three Dimensional Geometry (Figure 8.1.5). Write down the coordinates of all eight vertices.
🔗
Solution.
The base is on the floor, so its vertices have \(z = 0\text{:}\) \(O(0, 0, 0)\text{,}\) \(A(5, 0, 0)\text{,}\) \(B(5, 3, 0)\) and \(C(0, 3, 0)\text{.}\) \(B\) is \(5\) along \(x\) and \(3\) along \(y\text{.}\)
🔗
Each top vertex is \(2\) above the vertex below it, so it has the same \(x\) and \(y\) and \(z = 2\text{.}\) For example, \(E\) is above \(A\text{,}\) so \(x = 5\text{,}\) \(y = 0\text{,}\) \(z = 2\text{.}\) The top vertices are \(D(0, 0, 2)\text{,}\) \(E(5, 0, 2)\text{,}\) \(F(5, 3, 2)\) and \(G(0, 3, 2)\text{.}\)

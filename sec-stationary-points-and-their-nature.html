    Key Inquiry Questions 13.1.1.

    How can differentiation help us find the best possible value of a quantity, and describe how things move?
    🔗
    🔗
    In Grade 11 you learnt to differentiate: for \(y = x^n\text{,}\) \(\dfrac{dy}{dx} = nx^{n-1}\text{,}\) and the derivative of a sum is the sum of the derivatives. You used \(\dfrac{dy}{dx}\) to find the gradient of a curve at a point, the equations of tangents and normals, and the velocity \(v = \dfrac{ds}{dt}\) of a moving object. In this chapter you use the derivative to find where a curve turns, to sketch curves, to find the best value of a quantity, and to describe motion more fully.
    🔗
    Questions like these come up every day in Kenya. A fundi cutting a metal sheet into a water tank wants to use as little metal as possible. A juice seller in Mombasa wants the price that brings in the most profit. A drone flying over a tea estate in Kericho turns back and forth along a row, and its operator needs to know how far it has really flown. Each of these questions is answered by finding where a derivative is zero.
    🔗

    Subsection 13.1.1 Increasing and Decreasing Functions and Stationary Points

    Learner Experience 13.1.2 Walking the Ngong Hills Path.

    A walking path over the Ngong Hills is modelled by \(h = 4x^3 - 24x^2 + 45x\) for \(0 \le x \le 3.5\text{,}\) where \(x\) km is the distance along the path and \(h\) is the height above the trailhead in tens of metres.
    🔗
    1. Complete a table of \(h\) for \(x = 0, 0.5, 1, \ldots, 3.5\) and plot the path.
      🔗
      🔗
    2. Find \(\dfrac{dh}{dx}\) and its value at the same values of \(x\text{.}\)
      🔗
      🔗
    3. Where is the walker climbing, and where descending?
      🔗
      🔗
    4. Where is the gradient \(0\text{,}\) and what does the path look like there?
      🔗
      🔗
    5. Is the point at \(x = 1.5\) the highest point of the whole walk?
      🔗
      🔗
    🔗
    🔗

    Key Takeaway 13.1.3 Increasing, Decreasing and Stationary.

    A function \(f\) is increasing on an interval if \(f'(x) \gt 0\) at every \(x\) in it: the curve rises from left to right. It is decreasing on an interval if \(f'(x) \lt 0\) there: the curve falls.
    🔗
    A stationary point is a point where \(\dfrac{dy}{dx} = 0\text{.}\) The tangent is horizontal: the curve is momentarily neither rising nor falling. The \(y\)-coordinate of a stationary point is its stationary value. Always give both coordinates.
    🔗
    To find the stationary points of a curve: differentiate, solve \(\dfrac{dy}{dx} = 0\text{,}\) and substitute each solution into the equation of the curve to find \(y\text{.}\)
    🔗
    In this book an interval where a function increases or decreases is written with strict inequalities, such as \(-1 \lt x \lt 2\text{;}\) its ends are the stationary points.
    🔗
    🔗

    Example 13.1.5 Finding Stationary Points.

    Find the coordinates of the stationary points of \(y = x^3 + 3x^2 - 24x + 5\text{.}\)
    🔗
    Solution.
    Differentiate and factorise:
    \begin{equation*} \frac{dy}{dx} = 3x^2 + 6x - 24 = 3(x^2 + 2x - 8) = 3(x + 4)(x - 2) \end{equation*}
    So \(\dfrac{dy}{dx} = 0\) when \(x = -4\) or \(x = 2\text{.}\)
    🔗
    When \(x = -4\text{:}\) \(y = -64 + 48 + 96 + 5 = 85\text{.}\) When \(x = 2\text{:}\) \(y = 8 + 12 - 48 + 5 = -23\text{.}\)
    🔗
    The stationary points are \((-4, 85)\) and \((2, -23)\text{.}\)
    🔗
    🔗
    🔗

    Example 13.1.6 Where Is the Function Decreasing?

    Find the values of \(x\) for which \(f(x) = 2x^3 - 3x^2 - 12x + 1\) is decreasing.
    🔗
    Solution.
    \(f'(x) = 6x^2 - 6x - 12 = 6(x - 2)(x + 1)\text{,}\) which is \(0\) at \(x = -1\) and \(x = 2\text{.}\)
    🔗
    As with a quadratic inequality, sketch the graph of \(f'(x)\text{:}\) a “U” shape crossing the \(x\)-axis at \(-1\) and \(2\text{.}\) It is below the axis between the roots, so \(f'(x) \lt 0\) for \(-1 \lt x \lt 2\text{.}\)
    🔗
    So \(f\) is decreasing for \(-1 \lt x \lt 2\text{,}\) and increasing for \(x \lt -1\) and for \(x \gt 2\text{.}\)
    🔗
    🔗
    🔗

    Example 13.1.7 Only One Stationary Point.

    Find the stationary points of \(y = x^3 - 6x^2 + 12x - 3\text{.}\)
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 3x^2 - 12x + 12 = 3(x^2 - 4x + 4) = 3(x - 2)^2\text{.}\)
    🔗
    This is \(0\) only when \(x = 2\text{,}\) and then \(y = 8 - 24 + 24 - 3 = 5\text{.}\) There is one stationary point, \((2, 5)\text{.}\)
    🔗
    Because \(3(x - 2)^2 \ge 0\) for every \(x\text{,}\) the curve never falls. So what kind of point is \((2, 5)\text{?}\) It is not the top of a rise or the bottom of a dip. You will answer this in Example 13.1.17.
    🔗
    Some curves have no stationary point at all. For \(y = x^3 + 3x\text{,}\) \(\dfrac{dy}{dx} = 3x^2 + 3\text{,}\) which is always at least \(3\text{,}\) so it is never \(0\text{.}\)
    🔗
    🔗
    🔗
    Type whole numbers or fractions, for example -3 or 5/2. Type powers with ^, for example 2x^3-5x+1.
    🔗

    2.

    Find the coordinates of the stationary points of \(y = 2x^3 + 3x^2 - 36x + 10\text{.}\)
    🔗
    Answer.
    \((-3, 91)\) and \((2, -34)\)
    🔗
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 6x^2 + 6x - 36 = 6(x + 3)(x - 2)\text{,}\) so \(x = -3\) or \(x = 2\text{.}\) Then \(y = -54 + 27 + 108 + 10 = 91\) and \(y = 16 + 12 - 72 + 10 = -34\text{.}\)
    🔗
    🔗
    🔗

    3.

    Find the coordinates of the stationary points of \(y = 12x - 4x^3\text{.}\)
    🔗
    Answer.
    \((-1, -8)\) and \((1, 8)\)
    🔗
    🔗
    🔗

    4.

    Find the values of \(x\) for which \(f(x) = x^3 - 12x + 7\) is decreasing.
    🔗
    Answer.
    \(-2 \lt x \lt 2\)
    🔗
    🔗
    Solution.
    \(f'(x) = 3x^2 - 12 = 3(x - 2)(x + 2)\text{,}\) which is negative between its roots, so \(f\) is decreasing for \(-2 \lt x \lt 2\text{.}\)
    🔗
    🔗
    🔗

    5.

    The water level, \(h\) cm, in a tank at a school in Kitui, \(t\) hours after 6 a.m., is modelled by \(h = t^3 - 15t^2 + 63t + 40\) for \(0 \le t \le 10\text{.}\) When is the water level falling? Give the level at each stationary point.
    🔗
    Answer.
    Falling for \(3 \lt t \lt 7\text{,}\) that is from 9 a.m. to 1 p.m. The level is \(121\,\text{cm}\) at \(t = 3\) and \(89\,\text{cm}\) at \(t = 7\text{.}\)
    🔗
    🔗
    Solution.
    \(\dfrac{dh}{dt} = 3t^2 - 30t + 63 = 3(t - 3)(t - 7)\text{,}\) which is negative for \(3 \lt t \lt 7\text{.}\) \(h(3) = 27 - 135 + 189 + 40 = 121\) and \(h(7) = 343 - 735 + 441 + 40 = 89\text{.}\)
    🔗
    🔗
    🔗

    6.

    The curve \(y = x^3 + kx^2 + 5\) has a stationary point at \(x = 4\text{.}\) Find \(k\) and the coordinates of both stationary points.
    🔗
    Answer.
    \(k = -6\text{;}\) \((0, 5)\) and \((4, -27)\)
    🔗
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 3x^2 + 2kx\text{.}\) At \(x = 4\text{:}\) \(48 + 8k = 0\text{,}\) so \(k = -6\text{.}\) Then \(\dfrac{dy}{dx} = 3x^2 - 12x = 3x(x - 4)\text{,}\) which is \(0\) at \(x = 0\) and \(x = 4\text{;}\) \(y = 5\) and \(y = 64 - 96 + 5 = -27\text{.}\)
    🔗
    🔗
    🔗

    7. Challenge: A Curve That Never Stops Rising.

    Show that \(y = x^3 + 3x^2 + 6x - 1\) has no stationary points and is increasing for every \(x\text{.}\)
    🔗
    Hint.
    Complete the square in \(\dfrac{dy}{dx}\text{.}\)
    🔗
    🔗
    Answer.
    \(\dfrac{dy}{dx} = 3x^2 + 6x + 6 = 3\left((x + 1)^2 + 1\right) \ge 3 \gt 0\)
    🔗
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 3(x^2 + 2x + 2) = 3\left((x + 1)^2 + 1\right)\text{.}\) A square is never negative, so \(\dfrac{dy}{dx} \ge 3\) for every \(x\text{.}\) It is never \(0\text{,}\) so there are no stationary points, and it is always positive, so the curve is increasing everywhere.
    🔗
    🔗
    🔗
    🔗
    🔗

      🔗

      🔗

    4. Use the interactive in Figure 13.1.14 to make a cubic with two turning points, a cubic with a single stationary point that is not a turning point, and a cubic with no stationary points.

    Key Takeaway 13.1.11 The Nature of a Stationary Point.

    At a maximum point the curve rises to the point and falls after it: the gradient goes from positive to \(0\) to negative. At a minimum point the curve falls then rises: the gradient goes from negative to \(0\) to positive. Maximum and minimum points are called turning points.
    🔗
    At a point of inflection the curve flattens for an instant but carries on the same way: the gradient has the same sign on both sides.
    🔗
    A maximum point need not be the highest point of the whole curve: the curve may go higher elsewhere. That is why it is sometimes called a local maximum. Older Kenyan textbooks spell the third kind “point of inflexion”; it is the same thing.
    🔗
    🔗

    Example 13.1.15 Classifying with a Gradient Table.

    Find the stationary points of \(y = 2x^3 - 24x + 5\) and determine their nature.
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 6x^2 - 24 = 6(x - 2)(x + 2)\text{,}\) which is \(0\) at \(x = -2\) and \(x = 2\text{.}\) Then \(y = -16 + 48 + 5 = 37\) and \(y = 16 - 48 + 5 = -27\text{.}\)
    🔗
    Choose test values either side, but not beyond the other stationary point: \(x = -3\text{,}\) \(x = 0\) (between the two points, so it serves both) and \(x = 3\text{.}\)
    🔗
    So \((-2, 37)\) is a maximum point and \((2, -27)\) is a minimum point.
    🔗
    🔗
    🔗

    Example 13.1.17 A Point of Inflection.

    Determine the nature of the stationary point \((2, 5)\) of \(y = x^3 - 6x^2 + 12x - 3\) from Example 13.1.7.
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 3(x - 2)^2\text{.}\) At \(x = 1\) it is \(3\text{,}\) and at \(x = 3\) it is \(3\text{.}\) The pattern is \(+, 0, +\text{:}\) the curve rises, flattens for an instant at \((2, 5)\) and rises again. So \((2, 5)\) is a point of inflection.
    🔗
    🔗
    🔗

    Example 13.1.18 A Quartic with a Flat Step.

    Find the stationary points of \(y = x^4 - 4x^3\) and determine their nature.
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 4x^3 - 12x^2 = 4x^2(x - 3)\text{,}\) which is \(0\) at \(x = 0\) and \(x = 3\text{.}\) The points are \((0, 0)\) and \((3, 81 - 108) = (3, -27)\text{.}\)
    🔗
    So \((0, 0)\) is a point of inflection (the curve falls on both sides) and \((3, -27)\) is a minimum point.

    Key Takeaway 13.1.24 The Second Derivative Test.

    The second derivative, written \(\dfrac{d^2y}{dx^2}\) or \(f''(x)\text{,}\) is the derivative of \(\dfrac{dy}{dx}\text{.}\) It is the rate at which the gradient itself is changing. (In Grade 11 you met \(s''(t)\) as acceleration.)
    🔗
    At a stationary point:
    • if \(\dfrac{d^2y}{dx^2} \gt 0\text{,}\) the point is a minimum point;
      🔗
      🔗
    • if \(\dfrac{d^2y}{dx^2} \lt 0\text{,}\) the point is a maximum point;
      🔗
      🔗
    • if \(\dfrac{d^2y}{dx^2} = 0\text{,}\) the test is silent, not a verdict: use the gradient table.
      🔗
      🔗
    🔗
    🔗

    Warning 13.1.25 When the Second Derivative Is Zero.

    \(y = x^4\) has \(\dfrac{d^2y}{dx^2} = 12x^2 = 0\) at \(x = 0\text{,}\) but the origin is a minimum point. \(y = x^3\) also has \(\dfrac{d^2y}{dx^2} = 6x = 0\) at \(x = 0\text{,}\) and there the origin is a point of inflection. So \(\dfrac{d^2y}{dx^2} = 0\) does not mean a point of inflection. Use the gradient table (Figure 13.1.26).
    🔗
    🔗

    Example 13.1.27 Using the Second Derivative.

    Find the stationary points of \(f(x) = 2x^3 - 15x^2 + 36x - 20\) and use the second derivative to determine their nature.
    🔗
    Solution.
    \(f'(x) = 6x^2 - 30x + 36 = 6(x - 2)(x - 3)\text{,}\) so the stationary points are at \(x = 2\) and \(x = 3\text{:}\) \(f(2) = 16 - 60 + 72 - 20 = 8\) and \(f(3) = 54 - 135 + 108 - 20 = 7\text{.}\)
    🔗
    \(f''(x) = 12x - 30\text{.}\) \(f''(2) = -6 \lt 0\text{,}\) so \((2, 8)\) is a maximum point. \(f''(3) = 6 \gt 0\text{,}\) so \((3, 7)\) is a minimum point.
    🔗
    🔗
    🔗

    Example 13.1.28 When the Test Is Silent.

    Find the stationary points of \(y = 3x^4 - 8x^3 + 6\) and determine their nature.
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 12x^3 - 24x^2 = 12x^2(x - 2)\text{,}\) zero at \(x = 0\) and \(x = 2\text{.}\) The points are \((0, 6)\) and \((2, 48 - 64 + 6) = (2, -10)\text{.}\)
    🔗
    \(\dfrac{d^2y}{dx^2} = 36x^2 - 48x\text{.}\) At \(x = 2\) it is \(144 - 96 = 48 \gt 0\text{,}\) so \((2, -10)\) is a minimum point.
    🔗
    At \(x = 0\) it is \(0\text{,}\) so the test is silent. Use the gradient either side: at \(x = -1\text{,}\) \(\dfrac{dy}{dx} = -36\text{;}\) at \(x = 1\text{,}\) \(\dfrac{dy}{dx} = -12\text{.}\) The pattern is \(-, 0, -\text{,}\) so \((0, 6)\) is a point of inflection.
    🔗
    🔗

    Example 13.1.29 Finding Coefficients.

    The curve \(y = ax^3 + bx^2\) has a stationary point at \((2, -4)\text{.}\) Find \(a\) and \(b\text{,}\) and determine the nature of the point.
    🔗
    Solution.
    \(\dfrac{dy}{dx} = 3ax^2 + 2bx\text{.}\) The gradient is \(0\) at \(x = 2\text{:}\) \(12a + 4b = 0\text{.}\) The point lies on the curve: \(8a + 4b = -4\text{.}\)
    🔗
    Subtracting, \(4a = 4\text{,}\) so \(a = 1\) and \(b = -3\text{.}\) The curve is \(y = x^3 - 3x^2\text{.}\)
    🔗
    \(\dfrac{d^2y}{dx^2} = 6x - 6\text{,}\) which is \(6 \gt 0\) at \(x = 2\text{:}\) \((2, -4)\) is a minimum point.

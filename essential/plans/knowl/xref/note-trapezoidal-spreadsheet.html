Note 5.2.34 With a Spreadsheet.

Put the values of \(x\) in column A, the ordinates \(y\) in column B and the weights \(1, 2, 2, \ldots, 2, 1\) in column C, as in Example 5.2.12. With the data in rows 2 to 8 and the strip width in cell E1, the estimate is =SUMPRODUCT(B2:B8,C2:C8)*E1/2. To use more strips, add rows and change the weights.

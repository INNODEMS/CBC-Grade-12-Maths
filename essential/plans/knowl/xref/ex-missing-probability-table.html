Exercise 2.

\(X\) takes the values 1 to 5 with probabilities \(0.1\text{,}\) \(0.25\text{,}\) \(0.3\text{,}\) \(m\) and \(0.15\text{.}\) Find \(m\text{,}\) \(P(X \le 2)\) and \(P(X \gt 3)\text{.}\)
🔗
Answer.
\(m = 0.2\text{;}\) \(0.35\text{;}\) \(0.35\)
🔗
🔗
Solution.
\(m = 1 - (0.1 + 0.25 + 0.3 + 0.15) = 0.2\text{.}\) \(P(X \le 2) = 0.1 + 0.25 = 0.35\text{.}\) \(P(X \gt 3) = 0.2 + 0.15 = 0.35\text{.}\)

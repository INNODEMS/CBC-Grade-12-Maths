Exercise 6. Challenge: Integers Satisfying Both.

Find every integer \(x\) with \(5x - 4 \lt 26\) and \(1 - x \le 4\text{.}\)
🔗
Hint.
Solve each inequality first.
🔗
🔗
Answer.
\(-3, -2, -1, 0, 1, 2, 3, 4, 5\) (nine integers)
🔗
🔗
Solution.
\(5x \lt 30\text{,}\) so \(x \lt 6\text{.}\) \(1 \le 4 + x\text{,}\) so \(x \ge -3\text{.}\) Together \(-3 \le x \lt 6\text{:}\) the integers from \(-3\) to \(5\text{.}\)

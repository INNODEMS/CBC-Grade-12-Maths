Example 1.2.10 A Rule with an Inequality.

List the elements of \(\{x : x \text{ is a whole number}, 5x - 4 \lt 18\}\text{.}\)
🔗

Solution.

Solve the inequality first: \(5x \lt 22\text{,}\) so \(x \lt 4.4\text{.}\) The whole numbers less than \(4.4\) are \(0, 1, 2, 3, 4\text{,}\) so the set is \(\{0, 1, 2, 3, 4\}\text{.}\)

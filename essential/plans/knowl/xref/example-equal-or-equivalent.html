Example 1.3.7 Equal or Equivalent.

\(A = \{\text{factors of } 10\}\text{,}\) \(B = \{x : x \text{ is a whole number}, x \lt 4\}\) and \(C = \{10, 5, 2, 1\}\text{.}\) Compare \(A\) with \(B\text{,}\) and \(A\) with \(C\text{.}\)
🔗

Solution.

\(A = \{1, 2, 5, 10\}\) and \(B = \{0, 1, 2, 3\}\text{:}\) both have \(4\) elements but the elements differ, so \(A\) and \(B\) are equivalent but not equal. \(C\) has exactly the elements of \(A\) in a different order, so \(C = A\text{.}\)

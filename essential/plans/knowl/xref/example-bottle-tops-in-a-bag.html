Example 10.1.9 Bottle Tops in a Bag.

A bag holds \(15\) soda bottle tops: \(6\) red, \(5\) green and \(4\) white. One is taken at random. Find the probability that it is (a) red, (b) not white, (c) blue.
🔗

Solution.

There are \(15\) equally likely outcomes.
🔗
(a) \(P(\text{red}) = \dfrac{6}{15} = \dfrac{2}{5}\text{.}\)
🔗
(b) \(15 - 4 = 11\) bottle tops are not white, so \(P(\text{not white}) = \dfrac{11}{15}\text{.}\) Check: \(1 - \dfrac{4}{15} = \dfrac{11}{15}\text{.}\)
🔗
(c) There are no blue bottle tops, so \(P(\text{blue}) = 0\text{:}\) the event is impossible.
🔗

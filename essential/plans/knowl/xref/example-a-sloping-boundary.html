Example 3.3.11 A Sloping Boundary.

Show the region \(3x + 7y \le 21\text{.}\)
🔗

Solution.

Boundary \(3x + 7y = 21\text{.}\) Put \(x = 0\text{:}\) \(7y = 21\text{,}\) \(y = 3\text{,}\) so it crosses the \(y\)-axis at \((0, 3)\text{.}\) Put \(y = 0\text{:}\) \(3x = 21\text{,}\) \(x = 7\text{,}\) so it crosses the \(x\)-axis at \((7, 0)\text{.}\)
🔗
The sign is \(\le\text{,}\) so the line is solid.
🔗
Test \((0, 0)\text{:}\) \(3(0) + 7(0) = 0\) and \(0 \le 21\) is true. The origin is in \(R\text{,}\) so shade the side away from the origin.

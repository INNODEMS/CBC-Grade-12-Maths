Exercise 5.

Hiring a bus for a school trip costs Ksh \(4000\) plus Ksh \(150\) for each learner. The class wants the total cost to be between Ksh \(7000\) and Ksh \(9000\text{,}\) including both amounts. How many learners can go?
🔗
Answer.
From \(20\) to \(33\) learners.
🔗
🔗
Solution.
\(7000 \le 4000 + 150n \le 9000\text{.}\) Subtract \(4000\text{:}\) \(3000 \le 150n \le 5000\text{.}\) Divide by \(150\text{:}\) \(20 \le n \le 33\tfrac{1}{3}\text{.}\) \(n\) is a whole number, so \(20 \le n \le 33\text{.}\)

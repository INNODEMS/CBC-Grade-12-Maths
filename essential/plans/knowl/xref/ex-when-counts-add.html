Exercise 5.

Is \(n(A \cup B) = n(A) + n(B)\) always true? Give an example where it is true and one where it is not.
🔗
Answer.
Only when \(A \cap B = \varnothing\text{.}\) For example \(\{1, 2\}\) and \(\{3\}\) give \(3 = 2 + 1\text{,}\) but \(\{1, 2\}\) and \(\{2, 3\}\) give \(3 \neq 4\text{.}\)

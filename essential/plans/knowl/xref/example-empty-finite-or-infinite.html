Example 1.3.6 Empty, Finite or Infinite.

Is each set empty, finite (but not empty) or infinite?
🔗
  1. \(\displaystyle \{x : x \text{ is a natural number}, x^2 = 0\}\)
    🔗
    🔗
  2. \(\displaystyle \{x : x \text{ is a whole number}, x^2 = 0\}\)
    🔗
    🔗
  3. \(\displaystyle \{x : x \text{ is an integer}, x \gt -3\}\)
    🔗
    🔗
🔗

Solution.

(a) \(x^2 = 0\) only for \(x = 0\text{,}\) which is not a natural number: the set is \(\varnothing\text{.}\) (b) \(0\) is a whole number, so the set is \(\{0\}\text{:}\) finite, not empty. (c) \(\{-2, -1, 0, 1, 2, \ldots\}\) goes on for ever: infinite.

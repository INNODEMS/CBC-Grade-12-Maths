Example 4.2.7 Graphing One Constraint.

Graph \(5x + 6y \le 30\) and shade the unwanted side.
🔗

Solution.

The boundary is \(5x + 6y = 30\text{.}\) With \(y = 0\text{,}\) \(x = 6\text{;}\) with \(x = 0\text{,}\) \(y = 5\text{.}\) Draw the line through \((6, 0)\) and \((0, 5)\text{,}\) solid, since the sign is \(\le\text{.}\)
🔗
Test \((0, 0)\text{:}\) \(5(0) + 6(0) = 0 \le 30\) is true, so the origin is on the wanted side. Shade the side away from the origin.

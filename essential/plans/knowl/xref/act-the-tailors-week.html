Learner Experience 4.1.21 The Tailor’s Week.

A tailor in Kisumu makes school shirts and dresses. The table shows what each garment needs, what she has in a week, and the profit on each.
🔗
Let \(x\) be the number of shirts and \(y\) the number of dresses she makes in a week.
🔗
  1. Write the cloth constraint. Remove the decimals.
    🔗
    Solution.
    \(1.5x + 3.5y \le 63\text{;}\) doubling, \(3x + 7y \le 126\text{.}\)
    🔗
    🔗
    🔗
  2. Write the machine-time constraint.
    🔗
    Solution.
    \(x + 6y \le 64\text{.}\)
    🔗
    🔗
    🔗
  3. Write an expression for her weekly profit \(P\) in shillings.
    🔗
    Solution.
    \(P = 300x + 800y\text{.}\) There is no limit on profit, so this is not an inequality.
    🔗
    🔗
    🔗
  4. Can she make \(30\) shirts and \(5\) dresses? What profit would that give? Can she make \(20\) shirts and \(8\) dresses?
    🔗
    Solution.
    \((30, 5)\text{:}\) cloth \(90 + 35 = 125 \le 126\text{,}\) machine \(30 + 30 = 60 \le 64\text{,}\) so yes, with \(P = 9000 + 4000 = 13\,000\text{.}\) \((20, 8)\text{:}\) machine \(20 + 48 = 68 \gt 64\text{,}\) so no.
    🔗
    🔗
    🔗
  5. Which earns more, \(30\) shirts and \(5\) dresses, or \(28\) shirts and \(6\) dresses?
    🔗
    Solution.
    \((28, 6)\) is possible (cloth \(126\text{,}\) machine \(64\)) and gives \(P = 8400 + 4800 = 13\,200\text{,}\) more than Ksh \(13\,000\text{.}\) Section 4.3 shows how to find the best plan.
    🔗

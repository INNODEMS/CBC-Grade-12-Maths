Exercise 6. Challenge: The Same Inequality.

Show that \(6x + 14y \le 42\) and \(3x + 7y \le 21\) have exactly the same solutions.
🔗
Hint.
What happens when you divide by \(2\text{?}\)
🔗
🔗
Answer.
Dividing both sides of the first by the positive number \(2\) gives the second, so a pair makes one true exactly when it makes the other true.
🔗
🔗
Solution.
For any pair, \(6x + 14y = 2(3x + 7y)\) and \(42 = 2 \times 21\text{.}\) Dividing both sides of an inequality by a positive number keeps it true or keeps it false, so the two inequalities are true for exactly the same pairs.

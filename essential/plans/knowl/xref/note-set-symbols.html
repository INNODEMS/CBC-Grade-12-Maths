Note 1.1.2 Set Symbols in This Book.

  • \(\{\ \}\text{:}\) curly brackets (braces) hold the elements of a set, separated by commas, for example \(A = \{2, 4, 6\}\text{.}\)
    🔗
    🔗
  • \(x \in A\text{:}\) \(x\) is an element of \(A\text{.}\)
    🔗
    🔗
  • \(x \notin A\text{:}\) \(x\) is not an element of \(A\text{.}\)
    🔗
    🔗
  • \(n(A)\text{:}\) the number of elements in \(A\text{.}\)
    🔗
    🔗
🔗
Later sections add more symbols to this list, each where it is first needed.

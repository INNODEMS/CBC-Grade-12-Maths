    Key Takeaway 1.4.2 Union and Intersection.

    The union \(A \cup B\) is the set of elements in \(A\) or \(B\) or both, each element once. The intersection \(A \cap B\) is the set of elements in both \(A\) and \(B\text{.}\) When \(A\) and \(B\) have no element in common, \(A \cap B = \varnothing\text{.}\)
    🔗
    In the activity, \(F \cap N = \{\text{Cherono}, \text{Kevo}\}\) and \(F \cup N = \{\text{Amani}, \text{Bahati}, \text{Cherono}, \text{Dalmas}, \text{Kevo}, \text{Zawadi}\}\text{.}\)
    🔗
    🔗
    The symbols \(\cup\) and \(\cap\) join the list in Note 1.1.2.

    Example 1.4.4 Common Factors.

    \(A = \{\text{factors of } 20\}\) and \(B = \{\text{factors of } 44\}\text{.}\) Find \(A \cap B\text{,}\) \(A \cup B\) and \(n(A \cup B)\text{.}\)
    🔗
    Solution.
    \(A = \{1, 2, 4, 5, 10, 20\}\) and \(B = \{1, 2, 4, 11, 22, 44\}\text{.}\) So \(A \cap B = \{1, 2, 4\}\) and \(A \cup B = \{1, 2, 4, 5, 10, 11, 20, 22, 44\}\text{.}\) \(n(A \cup B) = 9\text{.}\) Notice that \(6 + 6 - 3 = 9\text{:}\) the \(3\) common factors would otherwise be counted twice.
    🔗
    🔗
    🔗

    Example 1.4.5 Three Sets.

    \(P = \{\text{factors of } 24\}\text{,}\) \(Q = \{\text{even numbers less than } 17\}\) and \(R = \{\text{multiples of 4 less than } 30\}\text{.}\) Find \(P \cap Q\text{,}\) \(Q \cap R\text{,}\) \(P \cap Q \cap R\) and \(P \cup R\text{.}\)
    🔗
    Solution.
    \(P = \{1, 2, 3, 4, 6, 8, 12, 24\}\text{,}\) \(Q = \{2, 4, 6, 8, 10, 12, 14, 16\}\text{,}\) \(R = \{4, 8, 12, 16, 20, 24, 28\}\text{.}\)
    🔗
    \(P \cap Q = \{2, 4, 6, 8, 12\}\text{;}\) \(Q \cap R = \{4, 8, 12, 16\}\text{;}\) \(P \cap Q \cap R = \{4, 8, 12\}\text{;}\) \(P \cup R = \{1, 2, 3, 4, 6, 8, 12, 16, 20, 24, 28\}\text{.}\)
    🔗
    🔗
    🔗

    Example 1.4.6 No Common Elements.

    \(M = \{4, 8, 12, 16\}\) and \(N = \{1, 3, 5, 7\}\text{.}\) Find \(M \cap N\) and \(n(M \cup N)\text{.}\)
    🔗
    Solution.
    \(M\) and \(N\) have no element in common, so \(M \cap N = \varnothing\) and \(n(M \cup N) = 4 + 4 = 8\text{.}\)
    🔗
    🔗
    🔗
    Sets with no element in common are called disjoint sets (Section 1.3).

    Key Takeaway 1.4.9 Complement and Difference.

    The complement of \(A\text{,}\) written \(A'\text{,}\) is everything in \(\xi\) that is not in \(A\text{.}\) So \(n(A') = n(\xi) - n(A)\text{.}\)
    🔗
    The difference \(A - B\) is the set of elements of \(A\) that are not in \(B\text{:}\) start with \(A\) and remove anything that is also in \(B\text{.}\) It is the same set as \(A \cap B'\text{.}\) In general \(A - B\) and \(B - A\) are different. Some books write \(A \setminus B\text{.}\)

    Example 1.4.10 Complements and Differences.

    \(\xi = \{x : x \text{ is a natural number}, x \le 14\}\text{,}\) \(A = \{4, 8, 12\}\) and \(B = \{x : x \text{ is a natural number}, x \le 6\}\text{.}\) List \(A'\text{,}\) \(A - B\text{,}\) \(B - A\) and \((A \cup B)'\text{.}\)
    🔗
    Solution.
    \(B = \{1, 2, 3, 4, 5, 6\}\text{.}\)
    🔗
    \(A' = \{1, 2, 3, 5, 6, 7, 9, 10, 11, 13, 14\}\text{;}\) \(A - B = \{8, 12\}\text{;}\) \(B - A = \{1, 2, 3, 5, 6\}\text{.}\)
    🔗
    \(A \cup B = \{1, 2, 3, 4, 5, 6, 8, 12\}\text{,}\) so \((A \cup B)' = \{7, 9, 10, 11, 13, 14\}\text{.}\)
    🔗
    🔗
    🔗

    Example 1.4.11 Brackets Matter.

    With the same sets, find \((A \cap B)'\) and \(A' \cap B\text{.}\)
    🔗
    Solution.
    \(A \cap B = \{4\}\text{,}\) so \((A \cap B)'\) is every element of \(\xi\) except \(4\text{:}\) \(13\) elements. \(A' \cap B\) is the elements of \(B\) that are not in \(A\text{:}\) \(\{1, 2, 3, 5, 6\}\text{.}\) The two sets are very different.
    🔗
    🔗
    🔗

    Example 1.4.12 Counting a Complement.

    A class has \(45\) learners, and \(28\) of them take Agriculture. How many do not?
    🔗
    Solution.
    \(n(A') = n(\xi) - n(A) = 45 - 28 = 17\text{.}\)
    🔗

    6. Challenge: Equal Differences.

    When is \(A - B = B - A\text{?}\)
    🔗
    Answer.
    Only when both are \(\varnothing\text{,}\) that is, when \(A = B\text{.}\)
    🔗
    🔗
    Solution.
    Every element of \(A - B\) is in \(A\) and every element of \(B - A\) is not in \(A\text{,}\) so the two sets can share no element. They can only be equal if both are empty. \(A - B = \varnothing\) means \(A \subseteq B\text{,}\) and \(B - A = \varnothing\) means \(B \subseteq A\text{,}\) so \(A = B\text{.}\)

\(\xi = \{1, 2, \ldots, 9\}\text{,}\) \(A = \{2, 5, 6, 9\}\) and \(B = \{1, 2, 3, 9\}\text{.}\) List \(A'\text{,}\) \(A - B\text{,}\) \(B - A\) and \((A \cup B)'\text{.}\)
🔗
Answer.
\(A' = \{1, 3, 4, 7, 8\}\text{;}\) \(A - B = \{5, 6\}\text{;}\) \(B - A = \{1, 3\}\text{;}\) \((A \cup B)' = \{4, 7, 8\}\)

Example 13.2.32 Counting Solutions.

Use the stationary points of \(y = x^3 - 3x + 2\) to find how many solutions the equation \(x^3 - 3x + 2 = k\) has for different values of \(k\text{.}\)
🔗

Solution.

\(\dfrac{dy}{dx} = 3x^2 - 3 = 3(x - 1)(x + 1)\text{,}\) so the stationary points are \((-1, 4)\text{,}\) a maximum point, and \((1, 0)\text{,}\) a minimum point. (In fact \(y = (x - 1)^2(x + 2)\text{.}\))
🔗
So \(x^3 - 3x + 2 = k\) has three solutions for \(0 \lt k \lt 4\text{,}\) two solutions for \(k = 0\) or \(k = 4\text{,}\) and one solution for \(k \lt 0\) or \(k \gt 4\text{.}\) For example, \(x^3 - 3x + 2 = 2\) has three solutions.

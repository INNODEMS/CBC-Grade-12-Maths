Exercise 6. Challenge: Parallel Combinations.

  1. Show that \(3\mathbf{p} - 2\mathbf{q}\) and \(4\mathbf{q} - 6\mathbf{p}\) are parallel for any vectors \(\mathbf{p}\) and \(\mathbf{q}\text{,}\) and say whether they point the same way.
    🔗
    🔗
  2. \(\mathbf{a} = 2\mathbf{i} - \mathbf{j} + \mathbf{k}\) and \(\mathbf{b} = \mathbf{i} + \mathbf{j} - \mathbf{k}\text{.}\) Find \(t\) so that \(\mathbf{a} + t\mathbf{b}\) is parallel to \(5\mathbf{i} + \mathbf{j} - \mathbf{k}\text{.}\)
    🔗
    🔗
🔗
Hint.
Write \(\mathbf{a} + t\mathbf{b}\) as a column.
🔗
🔗
Answer.
(a) \(4\mathbf{q} - 6\mathbf{p} = -2(3\mathbf{p} - 2\mathbf{q})\text{:}\) parallel, opposite directions (b) \(t = \frac{7}{4}\)
🔗
🔗
Solution.
(a) \(4\mathbf{q} - 6\mathbf{p} = -2(3\mathbf{p} - 2\mathbf{q})\text{,}\) a scalar multiple, so the two are parallel. The scalar is negative, so they point in opposite directions.
🔗
(b) \(\mathbf{a} + t\mathbf{b} = \begin{pmatrix} 2 + t \\ -1 + t \\ 1 - t \end{pmatrix}\text{.}\) For this to be \(c\begin{pmatrix} 5 \\ 1 \\ -1 \end{pmatrix}\text{:}\) \(-1 + t = c\) and \(1 - t = -c\) (the same equation), and \(2 + t = 5c = 5(t - 1)\text{,}\) so \(4t = 7\) and \(t = \frac{7}{4}\text{.}\) Then \(\mathbf{a} + t\mathbf{b} = \frac{3}{4}(5\mathbf{i} + \mathbf{j} - \mathbf{k})\text{.}\)

Exercise 6. Challenge: Equal Differences.

When is \(A - B = B - A\text{?}\)
🔗
Answer.
Only when both are \(\varnothing\text{,}\) that is, when \(A = B\text{.}\)
🔗
🔗
Solution.
Every element of \(A - B\) is in \(A\) and every element of \(B - A\) is not in \(A\text{,}\) so the two sets can share no element. They can only be equal if both are empty. \(A - B = \varnothing\) means \(A \subseteq B\text{,}\) and \(B - A = \varnothing\) means \(B \subseteq A\text{,}\) so \(A = B\text{.}\)

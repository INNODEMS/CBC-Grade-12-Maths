Example 2.3.9 Estimating \((0.97)^6\).

Use the expansion of \((1 + x)^6\) to estimate \((0.97)^6\text{,}\) correct to 4 decimal places.
🔗

Solution.

\(0.97 = 1 + (-0.03)\text{,}\) so put \(x = -0.03\) into \(1 + 6x + 15x^2 + 20x^3 + 15x^4 + \cdots\text{:}\)
\begin{equation*} 1 - 0.18 + 0.0135 - 0.00054 + 0.00001215 + \cdots \end{equation*}
The fifth term, \(0.00001215\text{,}\) is not smaller than \(0.00001\text{,}\) so it is included; the next term is \(6 \times (-0.03)^5 = -0.0000001458\text{,}\) so stop there. The sum is \(0.83297215\text{,}\) so \((0.97)^6 \approx 0.8330\text{.}\) A calculator gives \(0.832972004929\text{,}\) also \(0.8330\text{.}\) The terms alternate in sign because \(x\) is negative.

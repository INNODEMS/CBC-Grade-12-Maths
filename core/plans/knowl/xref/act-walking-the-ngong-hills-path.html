Learner Experience 13.1.3 Walking the Ngong Hills Path.

A walking path over the Ngong Hills is modelled by \(h = 4x^3 - 24x^2 + 45x\) for \(0 \le x \le 3.5\text{,}\) where \(x\) km is the distance along the path and \(h\) is the height above the trailhead in tens of metres.
🔗
  1. Complete a table of \(h\) for \(x = 0, 0.5, 1, \ldots, 3.5\) and plot the path.
    🔗
    Solution.
    \(h = 0, 17, 25, 27, 26, 25, 27, 35\text{.}\)
    🔗
    🔗
    🔗
  2. Find \(\dfrac{dh}{dx}\) and its value at the same values of \(x\text{.}\)
    🔗
    Solution.
    \(\dfrac{dh}{dx} = 12x^2 - 48x + 45\text{:}\) \(45, 24, 9, 0, -3, 0, 9, 24\text{.}\)
    🔗
    🔗
    🔗
  3. Where is the walker climbing, and where descending?
    🔗
    Solution.
    Climbing for \(0 \le x \lt 1.5\) and \(2.5 \lt x \le 3.5\) (gradient positive); descending for \(1.5 \lt x \lt 2.5\) (gradient negative).
    🔗
    🔗
    🔗
  4. Where is the gradient \(0\text{,}\) and what does the path look like there?
    🔗
    Solution.
    At \(x = 1.5\text{,}\) the top of a rise (\(h = 27\text{,}\) that is \(270\,\text{m}\)), and at \(x = 2.5\text{,}\) the bottom of a dip (\(h = 25\)). The path is momentarily flat at both.
    🔗
    🔗
    🔗
  5. Is the point at \(x = 1.5\) the highest point of the whole walk?
    🔗
    Solution.
    No: \(h = 35\) at \(x = 3.5\) is higher. The top of a rise is only highest nearby. (This returns in Subsection 13.3.2.)
    🔗

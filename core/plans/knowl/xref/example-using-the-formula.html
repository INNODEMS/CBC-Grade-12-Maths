Example 9.3.28 Using the Formula.

Solve \(3\cos^2 x + 5\sin x = 4\) for \(0^\circ \le x \le 360^\circ\text{.}\)
🔗

Solution.

Replace \(\cos^2 x\text{:}\) \(3 - 3\sin^2 x + 5\sin x = 4\text{,}\) so \(3\sin^2 x - 5\sin x + 1 = 0\text{.}\) This does not factorise, so use the formula:
\begin{equation*} \sin x = \frac{5 \pm \sqrt{25 - 12}}{6} = \frac{5 \pm \sqrt{13}}{6} = 1.4343 \text{ or } 0.2324 \end{equation*}
\(1.4343\) is rejected. \(\sin x = 0.2324\) gives \(13.4^\circ\) and \(180^\circ - 13.4^\circ = 166.6^\circ\text{.}\) So \(x \in \{13.4^\circ, 166.6^\circ\}\text{.}\)

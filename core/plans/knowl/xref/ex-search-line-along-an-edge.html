Exercise 4.

In Exercise 4.3.1.5, the maximum of \(P = 2x + 7y\) is reached all along an edge of R. Explain this using search lines.
🔗
Answer.
The search lines \(2x + 7y = k\) are parallel to the edge \(2x + 7y = 56\text{.}\)
🔗
🔗
Solution.
Every search line \(2x + 7y = k\) is parallel to the boundary \(2x + 7y = 56\text{.}\) Sliding away from the origin, the last search line that meets R is \(2x + 7y = 56\) itself, and it touches R along the whole edge from \((7, 6)\) to \((0, 8)\text{,}\) not at a single point.

Exercise 7. Challenge: A Curve That Never Stops Rising.

Show that \(y = x^3 + 3x^2 + 6x - 1\) has no stationary points and is increasing for every \(x\text{.}\)
🔗
Hint.
Complete the square in \(\dfrac{dy}{dx}\text{.}\)
🔗
🔗
Answer.
\(\dfrac{dy}{dx} = 3x^2 + 6x + 6 = 3\left((x + 1)^2 + 1\right) \ge 3 \gt 0\)
🔗
🔗
Solution.
\(\dfrac{dy}{dx} = 3(x^2 + 2x + 2) = 3\left((x + 1)^2 + 1\right)\text{.}\) A square is never negative, so \(\dfrac{dy}{dx} \ge 3\) for every \(x\text{.}\) It is never \(0\text{,}\) so there are no stationary points, and it is always positive, so the curve is increasing everywhere.

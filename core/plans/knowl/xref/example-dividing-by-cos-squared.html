Example 9.3.27 Dividing by \(\cos^2 x\).

Solve \(3\sin^2 x = \cos^2 x\) for \(0^\circ \le x \le 360^\circ\text{.}\)
🔗

Solution.

Divide by \(3\cos^2 x\text{:}\) \(\tan^2 x = \dfrac{1}{3}\text{,}\) so \(\tan x = \dfrac{1}{\sqrt{3}}\) or \(\tan x = -\dfrac{1}{\sqrt{3}}\text{.}\) The first gives \(30^\circ\) and \(210^\circ\text{;}\) the second gives \(150^\circ\) and \(330^\circ\text{.}\) So \(x \in \{30^\circ, 150^\circ, 210^\circ, 330^\circ\}\text{.}\)
🔗
No solution is lost by dividing: if \(\cos x = 0\) then \(\sin^2 x = 1\text{,}\) and \(3 \ne 0\text{.}\)

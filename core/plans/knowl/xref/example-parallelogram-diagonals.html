Example 10.9.8 Diagonals of a Parallelogram.

\(OABC\) is a parallelogram with \(\overrightarrow{OA} = \mathbf{a}\) and \(\overrightarrow{OC} = \mathbf{c}\text{.}\) Prove that its diagonals \(OB\) and \(AC\) bisect each other.
🔗

Solution.

\(\overrightarrow{OB} = \overrightarrow{OA} + \overrightarrow{AB} = \mathbf{a} + \mathbf{c}\text{,}\) since \(\overrightarrow{AB} = \overrightarrow{OC}\text{.}\) So the midpoint of \(OB\) has position vector \(\frac{1}{2}(\mathbf{a} + \mathbf{c})\text{.}\)
🔗
\(\overrightarrow{AC} = \mathbf{c} - \mathbf{a}\text{,}\) so the midpoint of \(AC\) has position vector \(\mathbf{a} + \frac{1}{2}(\mathbf{c} - \mathbf{a}) = \frac{1}{2}(\mathbf{a} + \mathbf{c})\text{.}\)
🔗
The two midpoints have the same position vector, so they are the same point: the diagonals meet at the midpoint of each, and bisect each other.

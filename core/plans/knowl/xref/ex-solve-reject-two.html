Exercise 3. Challenge: Only Two Angles.

Solve \(2\cos^2 x + 5\sin x = 4\) for \(0^\circ \le x \le 360^\circ\text{,}\) and explain why only two angles appear.
🔗
Hint.
Replace \(\cos^2 x\text{,}\) then factorise.
🔗
🔗
Answer.
\(\{30^\circ, 150^\circ\}\text{.}\) The quadratic \(2\sin^2 x - 5\sin x + 2 = (2\sin x - 1)(\sin x - 2) = 0\) has a root \(\sin x = 2\text{,}\) which is impossible.

Exercise 8. Challenge: Sum Given, Product Wanted.

An angle \(x\) has \(\sin x + \cos x = 1.2\text{.}\) Find \(\sin x \cos x\text{.}\)
🔗
Hint.
Square both sides.
🔗
🔗
Answer.
\(0.22\)
🔗
🔗
Solution.
\((\sin x + \cos x)^2 = \sin^2 x + \cos^2 x + 2\sin x\cos x = 1 + 2\sin x\cos x = 1.44\text{,}\) so \(\sin x\cos x = 0.22\text{.}\)

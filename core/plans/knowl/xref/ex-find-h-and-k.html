Exercise 5.

In triangle \(OAB\text{,}\) \(\overrightarrow{OA} = \mathbf{a}\) and \(\overrightarrow{OB} = \mathbf{b}\text{.}\) \(P\) is the midpoint of \(OA\) and \(Q\) is on \(AB\) with \(AQ : QB = 2 : 1\text{.}\) The lines \(BP\) and \(OQ\) meet at \(X\text{.}\) Find \(OX : XQ\) and \(BX : XP\text{.}\)
🔗
Answer.
\(OX : XQ = 3 : 1\text{;}\) \(BX : XP = 1 : 1\)
🔗
🔗
Solution.
\(\overrightarrow{OQ} = \frac{1}{3}(\mathbf{a} + 2\mathbf{b})\text{,}\) so \(\overrightarrow{OX} = h\overrightarrow{OQ} = \frac{h}{3}\mathbf{a} + \frac{2h}{3}\mathbf{b}\text{.}\) \(\overrightarrow{BP} = \frac{1}{2}\mathbf{a} - \mathbf{b}\text{,}\) so \(\overrightarrow{OX} = \mathbf{b} + k\overrightarrow{BP} = \frac{k}{2}\mathbf{a} + (1 - k)\mathbf{b}\text{.}\) Equating coefficients: \(\frac{h}{3} = \frac{k}{2}\) and \(\frac{2h}{3} = 1 - k\text{,}\) so \(k = 1 - k\text{,}\) \(k = \frac{1}{2}\) and \(h = \frac{3}{4}\text{.}\) So \(OX : XQ = 3 : 1\) and \(BX : XP = 1 : 1\text{.}\)

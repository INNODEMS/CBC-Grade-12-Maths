Exercise 1.

Expand (a) \((x + 5)^2\) (b) \((x + 5)^3\text{.}\)
🔗
Answer.
(a) \(x^2 + 10x + 25\) (b) \(x^3 + 15x^2 + 75x + 125\)
🔗
🔗
Solution.
(a) The grid gives \(x^2 + 5x + 5x + 25 = x^2 + 10x + 25\text{.}\) (b) \((x^2 + 10x + 25)(x + 5) = x^3 + 5x^2 + 10x^2 + 50x + 25x + 125 = x^3 + 15x^2 + 75x + 125\text{.}\)

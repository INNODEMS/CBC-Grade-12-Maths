Example 9.1.27 Cosine Known, Second Quadrant.

Given that \(\cos x = -0.6\) and \(90^\circ \lt x \lt 180^\circ\text{,}\) find \(\sin x\) and \(\tan x\text{.}\)
🔗

Solution.

\(\sin^2 x = 1 - (-0.6)^2 = 1 - 0.36 = 0.64\text{,}\) so \(\sin x = \pm 0.8\text{.}\) In the second quadrant sine is positive: \(\sin x = 0.8\text{.}\)
\begin{equation*} \tan x = \frac{0.8}{-0.6} = -\frac{4}{3} \end{equation*}

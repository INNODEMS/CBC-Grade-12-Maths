Answer.
(a) \(\{210^\circ, 330^\circ\}\) (b) \(\{0^\circ, 70.5^\circ, 289.5^\circ, 360^\circ\}\) (c) \(\{270^\circ\}\) (d) \(\{60^\circ, 300^\circ\}\) (e) \(\{14.5^\circ, 165.5^\circ, 270^\circ\}\)
🔗
🔗
Solution.
(a) \(2\sin^2 x - 9\sin x - 5 = (2\sin x + 1)(\sin x - 5) = 0\text{;}\) \(\sin x = 5\) is impossible. (b) \(3\cos^2 x - 4\cos x + 1 = (3\cos x - 1)(\cos x - 1) = 0\text{.}\) (c) \(\sin^2 x - \sin x - 2 = (\sin x - 2)(\sin x + 1) = 0\text{;}\) \(\sin x = 2\) is impossible. (d) \(4\cos^2 x - 4\cos x + 1 = (2\cos x - 1)^2 = 0\text{.}\) (e) \(4\sin^2 x + 3\sin x - 1 = (4\sin x - 1)(\sin x + 1) = 0\text{.}\)

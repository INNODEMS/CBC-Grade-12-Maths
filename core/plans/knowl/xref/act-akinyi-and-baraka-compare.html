Learner Experience 14.5.2 Akinyi and Baraka Compare.

Akinyi and Baraka, Grade 12 learners in Kisumu, want to know how good their estimates of the area under \(y = x^3\) from \(x = 0\) to \(x = 2\) are. Akinyi uses the trapezoidal rule and Baraka the mid-ordinate rule.
🔗
  1. Find the exact area by integration.
    🔗
    Solution.
    \(\left[\frac{x^4}{4}\right]_0^2 = 4\text{.}\)
    🔗
    🔗
    🔗
  2. Find Akinyi’s and Baraka’s estimates with \(2\) strips and with \(4\) strips. Read the values for \(8\) strips from the interactive in Figure 14.5.7.
    🔗
    Solution.
    Trapezoidal: \(5\text{,}\) \(4.25\text{,}\) \(4.0625\text{.}\) Mid-ordinate: \(3.5\text{,}\) \(3.875\text{,}\) \(3.96875\text{.}\)
    🔗
    🔗
    🔗
  3. For each estimate work out estimate \(-\) exact value.
    🔗
    Solution.
    Trapezoidal: \(1\text{,}\) \(0.25\text{,}\) \(0.0625\text{.}\) Mid-ordinate: \(-0.5\text{,}\) \(-0.125\text{,}\) \(-0.03125\text{.}\)
    🔗
    🔗
    🔗
  4. Express the size of each of these as a percentage of the exact value.
    🔗
    Solution.
    Trapezoidal: \(25\%\text{,}\) \(6.25\%\text{,}\) \(1.5625\%\text{.}\) Mid-ordinate: \(12.5\%\text{,}\) \(3.125\%\text{,}\) \(0.78125\%\text{.}\)
    🔗
    🔗
    🔗
  5. What happens to the errors each time the number of strips doubles?
    🔗
    Solution.
    Each error is divided by \(4\text{.}\)
    🔗
    🔗
    🔗
  6. Compare Akinyi’s error with Baraka’s for the same number of strips.
    🔗
    Solution.
    Baraka’s error is half the size of Akinyi’s and has the opposite sign.

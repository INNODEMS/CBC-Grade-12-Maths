Exercise 5.

A design for a shop signboard in Machakos is rotated \(90^{\circ}\) anticlockwise about \(O\) and then enlarged, centre \(O\text{,}\) scale factor \(3\text{.}\) Find the single matrix, and the image of the corner \((4, 1)\text{.}\)
🔗
Answer.
\(\begin{bmatrix} 0 \amp -3 \\ 3 \amp 0 \end{bmatrix}\text{;}\) \((-3, 12)\)
🔗
🔗
Solution.
The enlargement is done second, so it goes on the left: \(\begin{bmatrix} 3 \amp 0 \\ 0 \amp 3 \end{bmatrix}\begin{bmatrix} 0 \amp -1 \\ 1 \amp 0 \end{bmatrix} = \begin{bmatrix} 0 \amp -3 \\ 3 \amp 0 \end{bmatrix}\text{.}\) Then \(\begin{bmatrix} 0 \amp -3 \\ 3 \amp 0 \end{bmatrix}\begin{pmatrix} 4 \\ 1 \end{pmatrix} = \begin{pmatrix} -3 \\ 12 \end{pmatrix}\text{.}\)

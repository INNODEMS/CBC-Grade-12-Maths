Example 2.1.11 Squaring and Cubing \(x + 3\).

Expand (a) \((x + 3)^2\) (b) \((x + 3)^3\text{.}\)
🔗

Solution.

(a) Use a grid with \(x\) and \(3\) along the top and down the side.
🔗
Collecting the like terms \(3x + 3x = 6x\text{:}\)
\begin{equation*} (x + 3)^2 = x^2 + 6x + 9 \end{equation*}
🔗
(b) \((x + 3)^3 = (x^2 + 6x + 9)(x + 3)\text{.}\) Use a 2 by 3 grid.
🔗
Collecting like terms:
\begin{equation*} (x + 3)^3 = x^3 + 9x^2 + 27x + 27 \end{equation*}

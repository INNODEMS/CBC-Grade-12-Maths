Example 14.4.9 A Cubic.

For \(y = x^3 + 2\) from \(x = 0\) to \(x = 2\text{,}\) use \(4\) strips to find both estimates and the exact area.
🔗

Solution.

Here \(h = 0.5\text{.}\) The ordinates at \(x = 0, 0.5, 1, 1.5, 2\) are \(2, 2.125, 3, 5.375, 10\text{,}\) so
\begin{equation*} T = \tfrac{1}{2} \times 0.5 \times \left[2 + 10 + 2(2.125 + 3 + 5.375)\right] = 0.25 \times 33 = 8.25 \end{equation*}
The mid-ordinates at \(x = 0.25, 0.75, 1.25, 1.75\) are \(2.015625, 2.421875, 3.953125, 7.359375\text{,}\) which add to \(15.75\text{,}\) so \(M = 0.5 \times 15.75 = 7.875\text{.}\)
🔗
Exactly, \(\displaystyle\int_0^2 (x^3 + 2)\,dx = \left[\frac{x^4}{4} + 2x\right]_0^2 = 4 + 4 = 8\text{.}\)
🔗
On \(0 \le x \le 2\text{,}\) \(\dfrac{d^2y}{dx^2} = 6x \ge 0\text{:}\) the curve bends upwards, and indeed \(T = 8.25\) is too big and \(M = 7.875\) too small.

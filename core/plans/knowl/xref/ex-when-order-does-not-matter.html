Exercise 6. Challenge: When the Order Does Not Matter.

Show that the rotation of \(180^{\circ}\) about \(O\) followed by any transformation with matrix \(M\) has the same effect as \(M\) followed by the rotation of \(180^{\circ}\text{.}\)
🔗
Hint.
The rotation of \(180^{\circ}\) has matrix \(-I\text{.}\) Work out \(M(-I)\) and \((-I)M\text{.}\)
🔗
🔗
Answer.
\(M(-I) = -M = (-I)M\text{,}\) so the two single matrices are equal.
🔗
🔗
Solution.
Let \(M = \begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix}\text{.}\) The rotation first, then \(M\text{,}\) has matrix \(M\begin{bmatrix} -1 \amp 0 \\ 0 \amp -1 \end{bmatrix} = \begin{bmatrix} -a \amp -b \\ -c \amp -d \end{bmatrix}\text{.}\) \(M\) first, then the rotation, has matrix \(\begin{bmatrix} -1 \amp 0 \\ 0 \amp -1 \end{bmatrix}M = \begin{bmatrix} -a \amp -b \\ -c \amp -d \end{bmatrix}\text{.}\) The two single matrices are the same, so the order does not matter here.

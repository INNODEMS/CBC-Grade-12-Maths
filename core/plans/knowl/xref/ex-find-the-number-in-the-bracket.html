Exercise 5.

\((x + k)^3 = x^3 + 18x^2 + px + q\text{.}\) Find \(k\text{,}\) \(p\) and \(q\text{.}\)
🔗
Answer.
\(k = 6\text{,}\) \(p = 108\text{,}\) \(q = 216\)
🔗
🔗
Solution.
\((x + k)^3 = x^3 + 3kx^2 + 3k^2x + k^3\text{.}\) So \(3k = 18\text{,}\) giving \(k = 6\text{;}\) then \(p = 3k^2 = 108\) and \(q = k^3 = 216\text{.}\)

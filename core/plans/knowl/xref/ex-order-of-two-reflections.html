Exercise 1.

Find the single matrix, and name the single transformation, for each of these.
  1. The reflection in the line \(y = x\) followed by the reflection in the line \(y = -x\text{.}\)
    🔗
    🔗
  2. The reflection in the line \(y = -x\) followed by the reflection in the line \(y = x\text{.}\)
    🔗
    🔗
  3. The reflection in the \(x\)-axis followed by the reflection in the line \(y = x\text{.}\)
    🔗
    🔗
  4. The reflection in the line \(y = x\) followed by the reflection in the \(x\)-axis.
    🔗
    🔗
🔗
Answer.
(a) \(\begin{bmatrix} -1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\text{,}\) rotation of \(180^{\circ}\) about \(O\) (b) the same matrix and rotation: these two orders happen to agree (c) \(\begin{bmatrix} 0 \amp -1 \\ 1 \amp 0 \end{bmatrix}\text{,}\) rotation of \(90^{\circ}\) anticlockwise about \(O\) (d) \(\begin{bmatrix} 0 \amp 1 \\ -1 \amp 0 \end{bmatrix}\text{,}\) rotation of \(90^{\circ}\) clockwise about \(O\)
🔗
🔗
Solution.
(c) The reflection in the \(x\)-axis is done first, so it goes on the right: \(\begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix}\begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix} = \begin{bmatrix} 0 \amp -1 \\ 1 \amp 0 \end{bmatrix}\text{.}\) (d) \(\begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix} = \begin{bmatrix} 0 \amp 1 \\ -1 \amp 0 \end{bmatrix}\text{.}\) Two reflections always give a rotation; the order decides its direction.

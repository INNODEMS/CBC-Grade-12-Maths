Example 10.4.9 Distance Between Two Points.

Find the distance between \(A(1, 5, -2)\) and \(B(4, 1, 10)\text{.}\)
🔗

Solution.

\(\overrightarrow{AB} = \mathbf{b} - \mathbf{a} = \begin{pmatrix} 3 \\ -4 \\ 12 \end{pmatrix}\text{,}\) so
\begin{equation*} AB = \sqrt{3^2 + (-4)^2 + 12^2} = \sqrt{9 + 16 + 144} = \sqrt{169} = 13 \end{equation*}

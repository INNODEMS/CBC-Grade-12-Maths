Example 9.1.11 Deriving the Identity from a Triangle.

A right-angled triangle has sides \(7\text{,}\) \(24\) and \(25\text{.}\) The angle \(x\) is opposite the side \(7\text{.}\) Show that \(\sin^2 x + \cos^2 x = 1\text{,}\) then show the same for any right-angled triangle.
🔗

Solution.

\(\sin x = \dfrac{7}{25}\) and \(\cos x = \dfrac{24}{25}\text{,}\) so
\begin{equation*} \sin^2 x + \cos^2 x = \frac{49}{625} + \frac{576}{625} = \frac{625}{625} = 1 \end{equation*}
It works because \(7^2 + 24^2 = 25^2\text{.}\) In any right-angled triangle with sides \(o\text{,}\) \(a\) and hypotenuse \(h\text{,}\) Pythagoras gives \(o^2 + a^2 = h^2\text{,}\) so
\begin{equation*} \sin^2 x + \cos^2 x = \frac{o^2}{h^2} + \frac{a^2}{h^2} = \frac{o^2 + a^2}{h^2} = \frac{h^2}{h^2} = 1 \end{equation*}

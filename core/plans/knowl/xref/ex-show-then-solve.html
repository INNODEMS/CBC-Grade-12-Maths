  3. Solve \(3\sin^2 x - \cos^2 x = \cos x\) for \(0^\circ \le x \le 360^\circ\text{.}\)
    🔗
    🔗
🔗
Answer.
(b) \((4\cos x - 3)(\cos x + 1)\) (c) \(\{41.4^\circ, 180^\circ, 318.6^\circ\}\)
🔗
🔗
Solution.
(a) \(3(1 - \cos^2 x) - \cos^2 x = \cos x\text{,}\) so \(3 - 4\cos^2 x = \cos x\) and \(4\cos^2 x + \cos x - 3 = 0\text{.}\) (c) \(\cos x = \dfrac{3}{4}\) gives \(41.4^\circ\) and \(318.6^\circ\text{;}\) \(\cos x = -1\) gives \(180^\circ\text{.}\)

Example 10.9.11 Where Two Lines Meet.

In triangle \(OAB\text{,}\) \(\overrightarrow{OA} = \mathbf{a}\) and \(\overrightarrow{OB} = \mathbf{b}\text{.}\) \(C\) is on \(OA\) with \(OC : CA = 2 : 1\text{,}\) and \(D\) is on \(AB\) with \(AD : DB = 1 : 2\text{.}\) The lines \(OD\) and \(BC\) meet at \(X\text{.}\) Find the ratios \(OX : XD\) and \(BX : XC\text{.}\)
🔗

Solution.

Step 1: write the vectors. By the ratio theorem, \(\overrightarrow{OD} = \dfrac{2\mathbf{a} + \mathbf{b}}{3}\text{.}\) Also \(\overrightarrow{OC} = \frac{2}{3}\mathbf{a}\text{,}\) so \(\overrightarrow{BC} = \frac{2}{3}\mathbf{a} - \mathbf{b}\text{.}\)
🔗
Step 2: two routes to X. \(X\) is on \(OD\text{,}\) so \(\overrightarrow{OX} = h\overrightarrow{OD} = \frac{2h}{3}\mathbf{a} + \frac{h}{3}\mathbf{b}\) for some number \(h\text{.}\) \(X\) is also on \(BC\text{,}\) so \(\overrightarrow{OX} = \overrightarrow{OB} + k\overrightarrow{BC} = \frac{2k}{3}\mathbf{a} + (1 - k)\mathbf{b}\) for some number \(k\text{.}\)
🔗
Step 3: equate coefficients. \(\mathbf{a}\) and \(\mathbf{b}\) are not parallel, so
\begin{align*} \mathbf{a}:\amp\quad \frac{2h}{3} = \frac{2k}{3}, \text{ so } h = k\\ \mathbf{b}:\amp\quad \frac{h}{3} = 1 - k = 1 - h, \text{ so } h = \frac{3}{4} \end{align*}
Hence \(h = k = \frac{3}{4}\text{.}\) \(\overrightarrow{OX} = \frac{3}{4}\overrightarrow{OD}\text{,}\) so \(OX : XD = 3 : 1\text{;}\) and \(\overrightarrow{BX} = \frac{3}{4}\overrightarrow{BC}\text{,}\) so \(BX : XC = 3 : 1\text{.}\)

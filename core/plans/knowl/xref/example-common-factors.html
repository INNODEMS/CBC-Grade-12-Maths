Example 1.4.7 Common Factors.

\(A = \{\text{factors of } 20\}\) and \(B = \{\text{factors of } 44\}\text{.}\) Find \(A \cap B\text{,}\) \(A \cup B\) and \(n(A \cup B)\text{.}\)
🔗

Solution.

\(A = \{1, 2, 4, 5, 10, 20\}\) and \(B = \{1, 2, 4, 11, 22, 44\}\text{.}\) So \(A \cap B = \{1, 2, 4\}\) and \(A \cup B = \{1, 2, 4, 5, 10, 11, 20, 22, 44\}\text{.}\) \(n(A \cup B) = 9\text{.}\) Notice that \(6 + 6 - 3 = 9\text{:}\) the \(3\) common factors would otherwise be counted twice.

Example 5.2.9 Enlarge, Then Reflect.

\(E\) is the enlargement, centre \(O\text{,}\) scale factor \(2\text{,}\) and \(F\) is the reflection in the \(x\)-axis. Find the single matrix for “\(E\) followed by \(F\)”, and use it to find the final image of the point \((3, 1)\text{.}\)
🔗

Solution.

The matrices are \(E = \begin{bmatrix} 2 \amp 0 \\ 0 \amp 2 \end{bmatrix}\) and \(F = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\text{.}\) \(E\) is done first, so it goes on the right:
\begin{equation*} FE = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\begin{bmatrix} 2 \amp 0 \\ 0 \amp 2 \end{bmatrix} = \begin{bmatrix} 2 \amp 0 \\ 0 \amp -2 \end{bmatrix} \end{equation*}
The final image of \((3, 1)\) is
\begin{equation*} \begin{bmatrix} 2 \amp 0 \\ 0 \amp -2 \end{bmatrix}\begin{pmatrix} 3 \\ 1 \end{pmatrix} = \begin{pmatrix} 6 \\ -2 \end{pmatrix} \end{equation*}
so the point ends at \((6, -2)\text{.}\)
🔗
Here \(EF\) is also \(\begin{bmatrix} 2 \amp 0 \\ 0 \amp -2 \end{bmatrix}\text{.}\) An enlargement with centre \(O\) multiplies every coordinate by the same number, so it gives the same product in either order with any matrix. Most pairs of transformations are not like this.

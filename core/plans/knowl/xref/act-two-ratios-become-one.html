Learner Experience 9.3.2 Two Ratios Become One.

Solve \(2\sin^2 x + \cos x = 1\) for \(0^\circ \le x \le 360^\circ\text{.}\)
🔗
  1. Replace \(\sin^2 x\) using the identity.
    🔗
    Solution.
    \(2(1 - \cos^2 x) + \cos x = 1\text{.}\)
    🔗
    🔗
    🔗
  2. Rearrange into a quadratic equation in \(\cos x\text{.}\) Write \(c\) for \(\cos x\text{.}\)
    🔗
    Solution.
    \(2 - 2c^2 + c = 1\text{,}\) so \(2c^2 - c - 1 = 0\text{.}\)
    🔗
    🔗
    🔗
  3. Factorise and solve for \(c\text{.}\)
    🔗
    Solution.
    \((2c + 1)(c - 1) = 0\text{,}\) so \(c = -\dfrac{1}{2}\) or \(c = 1\text{.}\)
    🔗
    🔗
    🔗
  4. Find every \(x\) with \(0^\circ \le x \le 360^\circ\text{.}\)
    🔗
    Solution.
    \(\cos x = -\dfrac{1}{2}\text{:}\) \(120^\circ\) and \(240^\circ\text{.}\) \(\cos x = 1\text{:}\) \(0^\circ\) and \(360^\circ\text{.}\) So \(x \in \{0^\circ, 120^\circ, 240^\circ, 360^\circ\}\text{.}\)
    🔗
    🔗
    🔗
  5. In the interactive in Figure 9.3.6, set \(k = 1\) and compare the meeting points with your answers.
    🔗
    Solution.
    Four points, at \(0^\circ\text{,}\) \(120^\circ\text{,}\) \(240^\circ\) and \(360^\circ\text{.}\)

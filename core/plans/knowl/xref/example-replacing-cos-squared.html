Example 9.3.8 Replacing \(\cos^2 x\).

Solve \(3\cos^2 x + 2\sin x = 2\) for \(0^\circ \le x \le 360^\circ\text{.}\)
🔗

Solution.

The equation has \(\sin x\text{,}\) so replace \(\cos^2 x\) by \(1 - \sin^2 x\text{:}\)
\begin{align*} 3(1 - \sin^2 x) + 2\sin x \amp = 2\\ 3\sin^2 x - 2\sin x - 1 \amp = 0\\ (3\sin x + 1)(\sin x - 1) \amp = 0 \end{align*}
\(\sin x = 1\) gives \(90^\circ\text{.}\) \(\sin x = -\dfrac{1}{3}\text{:}\) the calculator gives \(-19.5^\circ\text{;}\) sine is negative in the third and fourth quadrants, so \(x = 180^\circ + 19.5^\circ = 199.5^\circ\) or \(360^\circ - 19.5^\circ = 340.5^\circ\text{.}\) So \(x \in \{90^\circ, 199.5^\circ, 340.5^\circ\}\text{.}\)

Example 9.1.12 Two More Identities.

Show that \(\tan x = \dfrac{\sin x}{\cos x}\) and that \(1 + \tan^2 x = \dfrac{1}{\cos^2 x}\) whenever \(\cos x \ne 0\text{.}\) Check the second at \(x = 60^\circ\text{.}\)
🔗

Solution.

In the triangle, \(\tan x = \dfrac{o}{a} = \dfrac{o/h}{a/h} = \dfrac{\sin x}{\cos x}\text{.}\) Grade 11 found the same result on the unit circle.
🔗
Divide every term of \(\sin^2 x + \cos^2 x = 1\) by \(\cos^2 x\text{:}\)
\begin{equation*} \frac{\sin^2 x}{\cos^2 x} + 1 = \frac{1}{\cos^2 x}, \quad\text{that is}\quad \tan^2 x + 1 = \frac{1}{\cos^2 x} \end{equation*}
At \(60^\circ\text{:}\) \(\tan 60^\circ = \sqrt{3}\) and \(\cos 60^\circ = 0.5\text{,}\) so the left side is \(1 + 3 = 4\) and the right side is \(\dfrac{1}{0.25} = 4\text{.}\)

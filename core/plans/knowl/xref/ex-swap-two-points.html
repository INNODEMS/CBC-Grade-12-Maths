Exercise 6. Challenge: Swapping Two Points.

Find the matrix that maps \((1, 2)\) onto \((2, 1)\) and \((2, 1)\) onto \((1, 2)\text{,}\) and describe the transformation fully.
🔗
Hint.
Write the two conditions as equations.
🔗
🔗
Answer.
\(\begin{bmatrix} 0 \amp 1 \\ 1 \amp 0 \end{bmatrix}\text{:}\) the reflection in the line \(y = x\)
🔗
🔗
Solution.
Let \(M = \begin{bmatrix} a \amp b \\ c \amp d \end{bmatrix}\text{.}\) Top rows: \(a + 2b = 2\) and \(2a + b = 1\text{,}\) so \(a = 0\text{,}\) \(b = 1\text{.}\) Bottom rows: \(c + 2d = 1\) and \(2c + d = 2\text{,}\) so \(c = 1\text{,}\) \(d = 0\text{.}\) The matrix sends \((1, 0)\) to \((0, 1)\) and \((0, 1)\) to \((1, 0)\text{:}\) it is the reflection in the line \(y = x\text{.}\)

Example 2.1.33 Expanding \((2x + 3)^3\).

Expand \((2x + 3)^3\text{.}\)
🔗

Solution.

Put \(a = 2x\) and \(b = 3\) into \(a^3 + 3a^2b + 3ab^2 + b^3\text{:}\)
\begin{align*} (2x + 3)^3 \amp = (2x)^3 + 3(2x)^2(3) + 3(2x)(3)^2 + 3^3\\ \amp = 8x^3 + 36x^2 + 54x + 27 \end{align*}
Check with \(x = 1\text{:}\) \(5^3 = 125\) and \(8 + 36 + 54 + 27 = 125\text{.}\)

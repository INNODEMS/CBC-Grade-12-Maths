Exercise 6.

The least value of \(f(x) = x^3 - 12x + k\) on \(0 \le x \le 3\) is \(3\text{.}\) Find \(k\text{.}\)
🔗
Answer.
\(k = 19\)
🔗
🔗
Solution.
The candidates are \(f(0) = k\text{,}\) \(f(2) = k - 16\) and \(f(3) = k - 9\text{.}\) The least is \(k - 16 = 3\text{,}\) so \(k = 19\text{.}\)

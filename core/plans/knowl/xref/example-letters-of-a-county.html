Example 1.1.8 Letters of a County.

List the set \(A = \{\text{letters of the word KIRINYAGA}\}\) and find \(n(A)\text{.}\)
🔗

Solution.

KIRINYAGA has nine letters, but I appears twice and A appears twice. Each element is written once, so \(A = \{\text{K}, \text{I}, \text{R}, \text{N}, \text{Y}, \text{A}, \text{G}\}\) and \(n(A) = 7\text{,}\) not \(9\text{.}\)

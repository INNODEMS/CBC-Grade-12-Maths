Exercise 7. Challenge: No Solutions.

Show that \(2\sin^2 x + \cos x = 3\) has no solutions.
🔗
Hint.
Write the equation as a quadratic in \(\cos x\) and look at its discriminant.
🔗
🔗
Answer.
\(2\cos^2 x - \cos x + 1 = 0\) has discriminant \(1 - 8 = -7 \lt 0\text{,}\) so there is no value of \(\cos x\text{.}\) (Also: the left side is never more than \(2.125\text{.}\))

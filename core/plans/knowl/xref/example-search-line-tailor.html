Example 4.3.30 Search Line for the Tailor.

Use a search line to find the tailor’s best plan for \(P = 300x + 800y\) on the region \(3x + 7y \le 126\text{,}\) \(x + 6y \le 64\text{,}\) \(x \ge 0\text{,}\) \(y \ge 0\text{.}\) Check your answer with gradients.
🔗

Solution.

Take \(k = 2400\text{,}\) a multiple of both \(300\) and \(800\text{.}\) The search line \(300x + 800y = 2400\) passes through \((8, 0)\) and \((0, 3)\text{.}\) Slide a ruler parallel to it, away from the origin. The last point of R it touches is the vertex where \(3x + 7y = 126\) and \(x + 6y = 64\) meet, \((28, 6)\text{.}\) There \(P = 13\,200\text{.}\)
🔗
Gradient check: the search line has gradient \(-\tfrac{300}{800} = -\tfrac{3}{8} = -0.375\text{.}\) The cloth edge \(3x + 7y = 126\) has gradient \(-\tfrac{3}{7} \approx -0.43\) and the machine edge \(x + 6y = 64\) has gradient \(-\tfrac{1}{6} \approx -0.17\text{.}\) Since \(-0.375\) lies between them, \((28, 6)\) is optimal: \(28\) shirts and \(6\) dresses, Ksh \(13\,200\text{,}\) as sampling found in Example 4.3.7.

Exercise 6.

A cubic \(y = x^3 + bx^2 + cx + d\) has a maximum point at \((-1, 6)\) and a minimum point at \((1, 2)\text{.}\) Find \(b\text{,}\) \(c\) and \(d\text{,}\) and sketch the curve.
🔗
Answer.
\(b = 0\text{,}\) \(c = -3\text{,}\) \(d = 4\text{:}\) \(y = x^3 - 3x + 4\text{,}\) \(y\)-intercept \(4\text{.}\)
🔗
🔗
Solution.
\(\dfrac{dy}{dx} = 3x^2 + 2bx + c\) must be \(3(x + 1)(x - 1) = 3x^2 - 3\text{,}\) so \(b = 0\) and \(c = -3\text{.}\) Then \(y(1) = 1 - 3 + d = 2\text{,}\) so \(d = 4\text{;}\) check \(y(-1) = -1 + 3 + 4 = 6\text{.}\)

    Subsection 9.1.1 Deriving the Identity \(\sin^2 x + \cos^2 x = 1\)

    Upon completion of this lesson, learners will be able to:
    1. Know: sine and cosine as ratios of sides and as unit-circle coordinates; why their squares add to 1; the difference between an identity and an equation.
      🔗
      🔗
    2. Do: derive the identity from any right-angled triangle; check it at any angle; obtain \(\tan x = \dfrac{\sin x}{\cos x}\) and \(1 + \tan^2 x = \dfrac{1}{\cos^2 x}\text{.}\)
      🔗
      🔗
    3. Apply: decide whether a statement is an identity.
      🔗
      🔗
    🔗

    Teacher Resource 9.1.2 Problem-Solving and Discovery.

    Suggested Time
    🔗
    14 minutes
    🔗
    Objective
    🔗
    Learners measure and discover that \(\sin^2 x + \cos^2 x = 1\text{,}\) then explain it with Pythagoras.
    🔗
    Teacher’s Role
    🔗
    Put learners in groups of four, each learner with one angle (\(20^\circ\text{,}\) \(35^\circ\text{,}\) \(50^\circ\) or \(70^\circ\)), a ruler and a protractor. A hypotenuse of \(10\,\text{cm}\) stands for 1 unit. After part (b) ask: “Why is your answer not exactly 1?” (measurement). Combine the four results of each group on the board, so every group sees all four angles.
    🔗
    🔗

    Learner Experience 9.1.3 Triangles with Hypotenuse 1.

    Each learner in your group takes one angle \(x\text{:}\) \(20^\circ\text{,}\) \(35^\circ\text{,}\) \(50^\circ\) or \(70^\circ\text{.}\)
    🔗
    1. Draw a right-angled triangle with hypotenuse \(10\,\text{cm}\) and one angle equal to your angle \(x\text{.}\) Measure the side opposite \(x\) and the side adjacent to \(x\text{,}\) to the nearest \(0.1\,\text{cm}\text{.}\)
      🔗
      Solution.
      Opposite and adjacent: \(3.4\) and \(9.4\) for \(20^\circ\text{;}\) \(5.7\) and \(8.2\) for \(35^\circ\text{;}\) \(7.7\) and \(6.4\) for \(50^\circ\text{;}\) \(9.4\) and \(3.4\) for \(70^\circ\) (all in cm).
      🔗
      🔗
      🔗
    2. Take \(10\,\text{cm}\) as 1 unit, so \(\sin x = \dfrac{\text{opposite}}{10}\) and \(\cos x = \dfrac{\text{adjacent}}{10}\text{.}\) Work out \(\sin^2 x + \cos^2 x\text{.}\)
      🔗
      Solution.
      \(0.9992\text{,}\) \(0.9973\text{,}\) \(1.0025\) and \(0.9992\text{:}\) each is very close to 1. The small differences come from measuring.
      🔗
      🔗
      🔗
    3. Write \(o\text{,}\) \(a\) and \(h\) for the opposite side, the adjacent side and the hypotenuse of any right-angled triangle. Use Pythagoras to show that \(\left(\dfrac{o}{h}\right)^2 + \left(\dfrac{a}{h}\right)^2 = 1\text{.}\)
      🔗
      Solution.
      \(\left(\dfrac{o}{h}\right)^2 + \left(\dfrac{a}{h}\right)^2 = \dfrac{o^2 + a^2}{h^2} = \dfrac{h^2}{h^2} = 1\text{,}\) because \(o^2 + a^2 = h^2\text{.}\)
      🔗
      🔗
      🔗
    4. A right-angled triangle cannot have an angle of \(150^\circ\text{.}\) Use the unit circle from Grade 11 (Figure 9.1.7) to check the result at \(150^\circ\text{.}\)
      🔗
      Solution.
      The point is \((\cos 150^\circ, \sin 150^\circ) = (-0.866, 0.5)\text{,}\) and \(0.75 + 0.25 = 1\text{.}\)
      🔗
      🔗
      🔗
    5. Use the interactive in Figure 9.1.8: drag the point all the way round the circle. Does the sum ever change?
      🔗
      Solution.
      No. It stays 1, even when \(\sin x\) or \(\cos x\) is negative, because squares are never negative.
      🔗
      🔗
      🔗
    🔗
    🔗

    Suggested Time

    Key Takeaway 9.1.5 The Pythagorean Identity.

    An identity is a statement that is true for every value of \(x\) for which both sides are defined. For every angle \(x\text{,}\)
    \begin{equation*} \sin^2 x + \cos^2 x = 1 \end{equation*}
    This is the Pythagorean identity: the three sides of a right-angled triangle obey Pythagoras, so the squares of sine and cosine always add to one.
    🔗
    \(\sin^2 x\) means \((\sin x)^2\text{,}\) the square of the sine. It is not \(\sin x^2\text{,}\) which is the sine of \(x^2\text{.}\) The identity can be rearranged as \(\sin^2 x = 1 - \cos^2 x\) or \(\cos^2 x = 1 - \sin^2 x\text{.}\)
    🔗
    🔗

    Example 9.1.10 Checking the Identity at \(230^\circ\).

    Use a calculator to check that \(\sin^2 x + \cos^2 x = 1\) when \(x = 230^\circ\text{.}\)
    🔗

    Solution.

    \(\sin 230^\circ = -0.7660\) and \(\cos 230^\circ = -0.6428\) (to 4 decimal places).
    \begin{equation*} \sin^2 230^\circ + \cos^2 230^\circ = 0.5868 + 0.4132 = 1.0000 \end{equation*}
    Both ratios are negative at \(230^\circ\text{,}\) but their squares are positive, so the identity still holds.
    🔗
    🔗
    🔗

    Example 9.1.11 Deriving the Identity from a Triangle.

    A right-angled triangle has sides \(7\text{,}\) \(24\) and \(25\text{.}\) The angle \(x\) is opposite the side \(7\text{.}\) Show that \(\sin^2 x + \cos^2 x = 1\text{,}\) then show the same for any right-angled triangle.
    🔗

    Solution.

    \(\sin x = \dfrac{7}{25}\) and \(\cos x = \dfrac{24}{25}\text{,}\) so
    \begin{equation*} \sin^2 x + \cos^2 x = \frac{49}{625} + \frac{576}{625} = \frac{625}{625} = 1 \end{equation*}
    It works because \(7^2 + 24^2 = 25^2\text{.}\) In any right-angled triangle with sides \(o\text{,}\) \(a\) and hypotenuse \(h\text{,}\) Pythagoras gives \(o^2 + a^2 = h^2\text{,}\) so
    \begin{equation*} \sin^2 x + \cos^2 x = \frac{o^2}{h^2} + \frac{a^2}{h^2} = \frac{o^2 + a^2}{h^2} = \frac{h^2}{h^2} = 1 \end{equation*}
    🔗
    🔗
    🔗

    Example 9.1.12 Two More Identities.

    Show that \(\tan x = \dfrac{\sin x}{\cos x}\) and that \(1 + \tan^2 x = \dfrac{1}{\cos^2 x}\) whenever \(\cos x \ne 0\text{.}\) Check the second at \(x = 60^\circ\text{.}\)
    🔗

    Solution.

    In the triangle, \(\tan x = \dfrac{o}{a} = \dfrac{o/h}{a/h} = \dfrac{\sin x}{\cos x}\text{.}\) Grade 11 found the same result on the unit circle.
    🔗
    Divide every term of \(\sin^2 x + \cos^2 x = 1\) by \(\cos^2 x\text{:}\)
    \begin{equation*} \frac{\sin^2 x}{\cos^2 x} + 1 = \frac{1}{\cos^2 x}, \quad\text{that is}\quad \tan^2 x + 1 = \frac{1}{\cos^2 x} \end{equation*}
    At \(60^\circ\text{:}\) \(\tan 60^\circ = \sqrt{3}\) and \(\cos 60^\circ = 0.5\text{,}\) so the left side is \(1 + 3 = 4\) and the right side is \(\dfrac{1}{0.25} = 4\text{.}\)
    🔗
    🔗
    🔗

    Note 9.1.13 Identity or Equation?

    \(\sin x + \cos x = 1\) is true at \(0^\circ\text{,}\) \(90^\circ\) and \(360^\circ\text{,}\) but at \(45^\circ\) the left side is \(1.41\text{.}\) So it is an equation, not an identity. One value of \(x\) where the two sides differ is enough to show a statement is not an identity. Trying a few values that work proves nothing: to show a statement is an identity, use algebra.

    2.

    A right-angled triangle has sides \(9\text{,}\) \(40\) and \(41\text{,}\) and \(x\) is the angle opposite the side \(9\text{.}\) Write down \(\sin x\) and \(\cos x\text{,}\) and show that \(\sin^2 x + \cos^2 x = 1\text{.}\)
    🔗
    Answer.
    \(\sin x = \dfrac{9}{41}\text{,}\) \(\cos x = \dfrac{40}{41}\text{;}\) \(\dfrac{81}{1681} + \dfrac{1600}{1681} = \dfrac{1681}{1681} = 1\text{.}\)
    🔗

    3.

    Use the identity to explain why \(-1 \le \sin x \le 1\) for every angle \(x\text{.}\)
    🔗
    Answer.
    \(\sin^2 x = 1 - \cos^2 x \le 1\) because \(\cos^2 x \ge 0\text{.}\) A number whose square is at most 1 lies between \(-1\) and \(1\text{.}\)
    🔗
    🔗
    🔗

    4.

    Divide \(\sin^2 x + \cos^2 x = 1\) by \(\sin^2 x\) to obtain a third identity. Check it at \(x = 30^\circ\text{.}\)
    🔗
    Answer.
    \(1 + \dfrac{1}{\tan^2 x} = \dfrac{1}{\sin^2 x}\) (where \(\sin x \ne 0\)). At \(30^\circ\text{:}\) \(1 + 3 = 4\) and \(\dfrac{1}{0.25} = 4\text{.}\)
    🔗
    🔗
    Solution.
    \(\dfrac{\sin^2 x}{\sin^2 x} + \dfrac{\cos^2 x}{\sin^2 x} = \dfrac{1}{\sin^2 x}\text{,}\) and \(\dfrac{\cos x}{\sin x} = \dfrac{1}{\tan x}\text{.}\) At \(30^\circ\text{,}\) \(\tan^2 30^\circ = \dfrac{1}{3}\text{.}\)
    🔗
    🔗
    🔗

    5.

    Show that \(\sin x + \cos x = 1\) is not an identity.
    🔗
    Answer.
    At \(x = 45^\circ\) the left side is \(0.71 + 0.71 = 1.41\text{,}\) not 1. One counterexample is enough.

    6. Challenge: A Point on a Circle.

    The point \(P(-5, 12)\) lies on a circle of radius 13 with centre \(O\text{.}\) Show that \(\left(-\dfrac{5}{13}\right)^2 + \left(\dfrac{12}{13}\right)^2 = 1\text{,}\) and find the angle \(x\) measured from the positive \(x\)-axis to \(OP\text{.}\)
    🔗
    Hint.
    \(\cos x = -\dfrac{5}{13}\) and \(\sin x = \dfrac{12}{13}\text{.}\) Which quadrant is \(P\) in?
    🔗
    🔗
    Answer.
    \(\dfrac{25}{169} + \dfrac{144}{169} = 1\text{;}\) \(x = 112.6^\circ\text{.}\)
    🔗
    🔗
    Solution.
    \(P\) is in the second quadrant. \(\cos^{-1}\left(-\dfrac{5}{13}\right) = 112.6^\circ\text{,}\) and \(\sin 112.6^\circ = 0.923 = \dfrac{12}{13}\text{,}\) as it should be.
